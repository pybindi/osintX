# Changelog

## 1.4.0

- Rich dashboard with numbered tools and Offline/Network labels.
- Nested result tables, explicit missing values and styled error panels.
- External text is rendered literally, without interpreting Rich markup.
- JSON output remains undecorated for scripts and pipelines.
- Windows launcher automatically uses `.venv` when available.
- Refreshed README with an actual rendered interface preview.
- Added Windows/Linux CI across Python 3.10, 3.12 and 3.13.

## 1.3.0

- Offline phone-number metadata independent of Telegram.
- Expanded IP metadata and readable nested results.
- Input validation and network-response regression tests.
